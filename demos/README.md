# Demo milestones

Each day runs independently. Open its folder as a NetBeans project where available, or use the matching Windows launcher in the repository root.

| Day | Features |
| --- | --- |
| 1 | Main window and empty schedule |
| 2 | Appointment entry and validation |
| 3 | Editing, deletion, saved appointments and schedule views |
| 4 | Recurrence, reminders and clash detection |
| 5 | Calendar export |
