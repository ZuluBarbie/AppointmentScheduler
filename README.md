# Appointment Scheduler: incremental group demos

This repository starts with the basic-window milestone on 2 November 2026. The demos are simplified teaching versions adapted from an existing local scheduler reference. The repository restart does not change that provenance.

## Run Day 1 on Windows

Java JDK 21 or newer is required.

1. Double-click **Run Day 1 Demo.cmd** once to compile and open the demo.
2. For later presentations, double-click the generated **Day 1 Demo** shortcut to open only the graphical window.
3. After changing source, run the `.cmd` again to rebuild. Old running windows do not prevent rebuilding.

The Day 1 window shows today's date and an empty read-only appointment table. Adding appointments comes on Day 2. Source: `demos/day1/src/demo/Main.java`.
